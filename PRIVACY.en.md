# Privacy note

- **The course collects no data.** No analytics, no tracking, no course servers.
- **The examples run on your machine.** The tests run offline with a mock client and send nothing anywhere.
- **When you use a real key,** your questions and the content of files the tools read are sent from your machine directly to the model provider, under that provider's privacy policy. Don't send personal or confidential data.
- **Never commit an API key** to this or any other repository. Keep it in an environment variable, as [Lesson 00](docs/en/00-setup/README.md) explains.
