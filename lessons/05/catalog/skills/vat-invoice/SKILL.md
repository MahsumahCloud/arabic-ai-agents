# فاتورة بضريبة القيمة المضافة

1. اقرأ البنود والأسعار، واقبل الأرقام العربية (١٥) واللاتينية (15).
2. اجمع البنود، ثم احسب الضريبة مرة واحدة على المجموع، وقرّب إلى أقرب هللة.
3. اعرض المجموع والضريبة والإجمالي، كل سطر وحده.
4. لا تستعمل أعداداً عشرية تقريبية للمال؛ استعمل حساباً عشرياً دقيقاً.
