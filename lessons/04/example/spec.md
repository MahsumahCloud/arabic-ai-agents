# المواصفات: حاسبة فاتورة بضريبة القيمة المضافة

> **ماذا ولماذا فقط.** لا لغة برمجة هنا ولا أسماء ملفات؛ تلك مكانها الخطة.

## الفكرة كما قالها صاحبها

«صاحب مقهى صغير يريد أن يكتب بنود الطلب وأسعارها، فيرى المجموع والضريبة والإجمالي فوراً، ويكتب الأرقام كما اعتاد، بالعربية أو بالإنجليزية.»

## المستخدم وقصته

صاحب مقهى يُصدر فواتير يدوية. يكتب كل بند وسعره قبل الضريبة، ويريد أن يعرف ثلاثة أرقام: المجموع قبل الضريبة، ومبلغ الضريبة، والإجمالي. وقد يعرف السعر شاملاً الضريبة ويريد أن يفصل الضريبة منه.

## المتطلبات

- م-1: يكتب المستخدم كل بند بالصيغة «الاسم=المبلغ»، ويُقبل المبلغ بالأرقام العربية الهندية أو الإنجليزية، مع الفاصلة العشرية العربية (٫) أو النقطة، ومع فاصل الآلاف.
- م-2: تُحسب ضريبة القيمة المضافة بنسبة 15٪ مرة واحدة على مجموع البنود قبل الضريبة، لا على كل بند منفرداً.
- م-3: يُقرَّب كل مبلغ معروض إلى أقرب هللة، والنصف إلى الأعلى.
- م-4: إذا أعطى المستخدم سعراً شاملاً الضريبة، تفصله الحاسبة إلى صافٍ وضريبة، ومجموعهما يساوي السعر الأصلي بالهللة دون فرق.
- م-5: تُعرض الفاتورة بالعربية: سطر لكل بند، ثم المجموع قبل الضريبة، ثم الضريبة، ثم الإجمالي، وكل مبلغ برمز الريال الرسمي.
- م-6: المدخل الخاطئ (فارغ، أو سالب، أو ليس رقماً، أو بلا علامة «=») يُرفض برسالة عربية واضحة، ولا تُعرض فاتورة ناقصة.

## سيناريوهات القبول

| بافتراض | عندما | فإن |
|---|---|---|
| بندان: قهوة بـ ١٥ وكعكة بـ ٢٢٫٥ | تُحسب الفاتورة | المجموع 37.50، والضريبة 5.63، والإجمالي 43.13 |
| سعر شامل الضريبة 115 | يُطلب الفصل | الصافي 100.00 والضريبة 15.00 |
| سعر شامل الضريبة 10 | يُطلب الفصل | الصافي 8.70 والضريبة 1.30، ومجموعهما 10.00 بالضبط |
| بند مكتوب «شاي=-٥» | تُحسب الفاتورة | رسالة «المبلغ لا يكون سالباً» ولا فاتورة |
| مبلغ «1,250» | يُقرأ المبلغ | يُفهم ألفاً ومئتين وخمسين |

## خارج النطاق

- الخصومات، والعملات الأخرى، وطباعة الفاتورة أو حفظها.
- متطلبات الفوترة الإلكترونية ورموزها، وأي ربط بأنظمة حكومية.

## أسئلة حُسمت قبل الخطة

- هل تُحسب الضريبة على كل بند أم على المجموع؟ **حُسم:** على المجموع (م-2)، حتى لا تتراكم فروق التقريب.
- هل نقبل الفاصلة «,» فاصلاً عشرياً؟ **حُسم:** لا، هي فاصل آلاف فقط، والفاصلة العشرية هي «٫» أو النقطة (م-1).
