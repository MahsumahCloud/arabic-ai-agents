# المهام: قائمة التنفيذ

> كل مهمة صغيرة، ولها متطلب أو أكثر بين قوسين. اقرأ القائمة كاملة قبل أن تسمح للوكيل بالبناء، ثم علّم كل مهمة عند إنجازها.

## التجهيز

- [x] ت-1 (م-3): ثابت نسبة الضريبة وثابت الهللة ودالة التقريب إلى أقرب هللة، مع اختبار لحالة النصف.

## الأساس

- [x] ت-2 (م-1): دالة قراءة المبلغ: تحويل الأرقام العربية الهندية والفاصلتين، وحذف فاصل الآلاف.
- [x] ت-3 (م-6): رفض المبلغ الفارغ والسالب وغير الرقمي برسالة عربية، مع اختبار لكل حالة.
- [x] ت-4 (م-1، م-6): قراءة البند بالصيغة «الاسم=المبلغ»، ورفض البند بلا «=» أو بلا اسم.

## القصة الأساسية: فاتورة من بنود

- [x] ت-5 (م-2، م-3): حساب المجموع ثم الضريبة على المجموع ثم الإجمالي، واختبار سيناريو القهوة والكعكة.
- [x] ت-6 (م-5): عرض الفاتورة بالعربية، وتنسيق كل مبلغ بخانتين وفاصل آلاف ورمز الريال.

## القصة الثانية: فصل الضريبة من سعر شامل

- [x] ت-7 (م-4): دالة الفصل، واختبار أن الصافي والضريبة يساويان الأصل بالهللة لأسعار من 0.01 إلى 1000.

## الإنهاء

- [x] ت-8 (م-6): واجهة الأوامر: تلتقط الأخطاء وتطبع رسالة عربية وتعيد رمز خروج غير صفري.
