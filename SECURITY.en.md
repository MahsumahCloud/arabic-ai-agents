# Security policy

## Reporting a vulnerability

If you find a security vulnerability in the course code, such as a way to escape the sandbox in `lessons/02/tools.py` or to run a dangerous tool without approval, report it **privately** to [security@mahsumaah.sa](mailto:security@mahsumaah.sa).

- **Don't open a public issue** about the vulnerability before it is fixed.
- Include the file, the steps to reproduce it, and the expected impact.
- We'll acknowledge your report, keep you informed of what we do, and credit you in the changelog if you wish.

## Scope

The scope is this repository's code and text. Vulnerabilities in third-party libraries or services should be reported to their owners directly.

## If a key leaks

If you see an API key in any file or pull request, tell us right away at the same address. If it's your own key, revoke it in the provider's console before anything else.
