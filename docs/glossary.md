# المسرد

المصطلحات مرتبة حسب ظهورها في الدروس. المصطلح الإنجليزي بين قوسين مرة واحدة، ليسهل عليك البحث في المراجع الأجنبية.

| المصطلح | التعريف | الدرس |
|---|---|---|
| البيئة الافتراضية (Virtual Environment) | مجلد معزول يحمل مكتبات مشروع واحد حتى لا تتعارض مع غيره | 00 |
| متغير البيئة (Environment Variable) | قيمة يضبطها نظام التشغيل خارج الشيفرة، ومنها يُقرأ مفتاح API | 00 |
| مفتاح API (API Key) | سرّ يثبت هويتك عند الواجهة البرمجية، ويُعامل ككلمة المرور | 00 |
| الرمز (Token) | قطعة من النص هي وحدة القياس والتسعير عند النموذج | 00 |
| مستوى الجهد (Effort) | إعداد يحدد مقدار تفكير النموذج واستهلاكه للرموز | 00 |
| صندوق الرمل (Sandbox) | مساحة معزولة لا تستطيع الأدوات تجاوزها | 00 |
| أقل صلاحية (Least Privilege) | منح أي مكوّن أقل قدر من الصلاحيات يكفي لعمله | 00 |
| عميل وهمي (Mock Client) | بديل للعميل الحقيقي يعيد ردوداً مكتوبة مسبقاً لأغراض الاختبار | 00 |
| النموذج اللغوي الكبير (Large Language Model) | نموذج مدرَّب على نصوص كثيرة يولّد نصاً مناسباً لما يُعطى له | 01 |
| الوكيل (Agent) | نظام يستعمل نموذجاً ليقرر خطواته بنفسه داخل حلقة، باستعمال أدوات، حتى يتحقق الهدف أو يُبلغ حدّ التوقف | 01 |
| سير العمل (Workflow) | سلسلة خطوات تحددها الشيفرة مسبقاً، وقد يُستعمل النموذج في بعضها | 01 |
| الحلقة (Loop) | تكرار: إدراك ثم تفكير ثم فعل، حتى شرط التوقف | 01 |
| الإدراك (Perceive) | ما يعرفه الوكيل الآن: الطلب ونتائج الأدوات | 01 |
| التفكير (Think) | اختيار الخطوة التالية | 01 |
| الفعل (Act) | تنفيذ الخطوة في البيئة | 01 |
| البيئة (Environment) | العالم الذي يتأثر بأفعال الوكيل ويعيد النتائج | 01 |
| شرط التوقف (Stopping Condition) | قاعدة تنهي الحلقة: هدف تحقّق أو حدّ بُلغ | 01 |
| تعليمات النظام (System Prompt) | تعليمات عامة تحدد دور النموذج وقواعده في المحادثة | 01 |
| كتلة المحتوى (Content Block) | جزء من الرد له نوع: نص أو تفكير أو طلب أداة | 01 |
| سبب التوقف (Stop Reason) | الحقل `stop_reason` الذي يخبرك لماذا توقف النموذج | 01 |
| التفكير التكيّفي (Adaptive Thinking) | تفكير يقرر النموذج مقداره بحسب صعوبة الطلب | 01 |
| الأداة (Tool) | قدرة تعرّفها للنموذج وتنفّذها شيفرتك عند طلبه | 02 |
| استخدام الأدوات (Tool Use) | آلية يطلب بها النموذج تشغيل أداة ويتلقى نتيجتها | 02 |
| مخطط JSON (JSON Schema) | وصف منظم لشكل البيانات المقبولة كمدخلات للأداة | 02 |
| نتيجة الأداة (Tool Result) | الكتلة `tool_result` التي تعيد بها نتيجة الأداة أو خطأها | 02 |
| الاستدعاء المتوازي (Parallel Tool Use) | طلب عدة أدوات في رد واحد | 02 |
| قائمة السماح (Allowlist) | تحديد المسموح صراحة ورفض ما عداه | 02 |
| شجرة النحو المجردة (Abstract Syntax Tree) | تمثيل شجري للتعبير يسمح بفحصه قبل حسابه، بدل `eval` | 02 |
| الموافقة البشرية (Human Approval) | اشتراط موافقة إنسان قبل تنفيذ فعل خطر | 02 |
| حقن التعليمات (Prompt Injection) | نص مدسوس في بيانات يقرؤها النموذج يحاول تغيير سلوكه | 02 |
| مُشغّل الأدوات (Tool Runner) | أداة في المكتبة الرسمية تدير حلقة الأدوات عنك (تجريبية) | 02 |
| التخطيط (Planning) | كتابة خطوات العمل قبل التنفيذ بصيغة يمكن فحصها | 03 |
| ذاكرة المحادثة (Conversation Memory) | قائمة الرسائل التي ترسلها شيفرتك كاملة في كل طلب | 03 |
| تاريخ إضافي فقط (Append-only History) | قاعدة: يُضاف إلى المحادثة ولا يُعدَّل ما سبق | 03 |
| التطبيع (Normalization) | توحيد صور الحروف وحذف التشكيل قبل المقارنة | 03 |
| الكلمات الشائعة المستبعدة (Stop Words) | كلمات كثيرة الورود تُستبعد من البحث | 03 |
| الاستشهاد (Citation) | إشارة إلى المستند والسطر الذي جاءت منه المعلومة | 03 |
| الإسناد إلى المصادر (Grounding) | ربط الإجابة بمصادر فعلية بدل المعرفة العامة للنموذج | 03 |
| حدّ الخطوات (Max Steps) | أقصى عدد دورات مسموح بها للحلقة | 03 |
| حدّ الكلفة (Cost Budget) | أقصى مبلغ يُسمح بإنفاقه على سؤال واحد | 03 |
| كشف التكرار (Loop Detection) | اكتشاف أن الوكيل يكرر الاستدعاء نفسه بلا تقدم | 03 |
| بيانات الاستهلاك (Usage) | عدد رموز الإدخال والإخراج والتخزين المؤقت في كل رد | 03 |
| التخزين المؤقت للطلبات (Prompt Caching) | إعادة استعمال بداية طلب مكررة بسعر أقل | 03 |
| الضغط (Compaction) | تلخيص بداية المحادثة الطويلة تلقائياً لتبقى ضمن السياق | 03 |
| التطوير الموجّه بالمواصفات (Spec-Driven Development) | طريقة عمل تُكتب فيها القرارات أولاً بلغة واضحة ويراجعها إنسان، ثم تُبنى الشيفرة منها | 04 |
| الدستور (Constitution) | ملف قصير بقواعد المشروع التي لا تُكسر، ومنها ما لا يُلمس، يُقرأ قبل كل ميزة | 04 |
| المواصفات (Specification) | وصف ما نبنيه ولمن ولماذا، بمتطلبات مرقّمة وسيناريوهات قبول، دون تقنية | 04 |
| المتطلب (Requirement) | جملة واحدة مرقّمة تقول شيئاً يمكن اختباره | 04 |
| سيناريو القبول (Acceptance Scenario) | مثال بأرقام حقيقية: بافتراض كذا، عندما يحدث كذا، فإن النتيجة كذا | 04 |
| خارج النطاق (Out of Scope) | ما قرّرنا صراحة ألا نبنيه في هذه الميزة | 04 |
| الخطة التقنية (Technical Plan) | كيف سنبني الميزة: التقنية والملفات والقرارات، وكل قرار يذكر المتطلب الذي يخدمه | 04 |
| قائمة المهام (Task List) | خطوات صغيرة مرتّبة، كل خطوة تشير إلى متطلب وتُعلَّم عند إنجازها | 04 |
| التتبّع (Traceability) | ربط كل سطر من الشيفرة بمهمة ومتطلب، وكل متطلب باختبار | 04 |
| التقارب (Convergence) | مقارنة الشيفرة بالمواصفات بعد التنفيذ، وإضافة مهام لما نقص حتى لا يبقى نقص | 04 |
| بوابة المراجعة (Review Gate) | نقطة لا يبدأ بعدها التنفيذ قبل أن يقرأ إنسان المواصفات والمهام ويوافق | 04 |
| حكم التحقق (Verification Verdict) | نتيجة مسار إصلاح الخطأ: تحقّق، أو جزئي، أو فشل | 04 |
| تقييم الفكرة (Idea Assessment) | أسئلة قبل البناء تنتهي بقرار: امضِ، أو وضّح، أو توقّف | 04 |
| مهارة الوكيل (Agent Skill) | مجلد فيه ملف تعليمات لعمل واحد، يحمّله الوكيل حين يحتاجه فقط | 05 |
| ملف المهارة (SKILL.md) | الملف الإلزامي في المهارة: رأس فيه الاسم والوصف، ثم التعليمات | 05 |
| رأس الملف (Front Matter) | الأسطر بين علامتي `---` في أول الملف، وفيها الحقول مثل الاسم والوصف | 05 |
| وصف المهارة (Skill Description) | جملة تقول ماذا تفعل المهارة ومتى تُستعمل، وبها وحدها يقرر الوكيل أن يفتحها | 05 |
| التحميل التدريجي (Progressive Loading) | الوصف دائماً، والتعليمات عند التطابق، والسكربتات والموارد عند الطلب فقط | 05 |
| فهرس المهارات (Skill Catalogue) | قائمة بالمهارات المتاحة للتثبيت، مع مكان كل منها وعلامات الثقة فيها | 05 |
| علامات الثقة (Trust Signals) | ما يرجّح أن المهارة سليمة، مثل توثيق المصدر وعدد التثبيتات | 05 |
| مصدر موثّق (Verified Source) | مصدر راجعه ناشر الفهرس، وهو أقوى علامات الثقة | 05 |
| المهارة المحجوبة (Held-back Skill) | مهارة تطابق الطلب لكن ثقتها منخفضة، فلا تُقترح أبداً | 05 |
| معاينة التثبيت (Install Preview) | ما يُعرض قبل التثبيت: الاسم والوصف والمصدر والملفات والتنبيهات | 05 |
| الموافقة الصريحة (Explicit Consent) | «نعم» واضحة من المستخدم؛ الصمت أو «ربما» ليسا موافقة | 05 |
| اجتياز المسار (Path Traversal) | محاولة الكتابة أو القراءة خارج المجلد المسموح بمسار مثل `../` | 05 |
| الرابط الرمزي (Symbolic Link) | ملف يشير إلى ملف آخر، قد يكون خارج المجلد الذي يبدو فيه | 05 |
