# الدرس 00: تجهيز بيئة العمل

> [!NOTE]
> **ستتعلم في هذا الدرس**
>
> - تثبيت Python ومكتبة Anthropic الرسمية في بيئة افتراضية (Virtual Environment).
> - حفظ مفتاح API في متغير بيئة (Environment Variable)، لا في الشيفرة.
> - فهم طريقة حساب الكلفة، وكيف تضع لنفسك حدوداً.
> - تشغيل اختبارات الدورة دون مفتاح ودون إنترنت.
>
> **المدة المتوقعة:** 20 دقيقة · **ستخرج من هذا الدرس بـ:** بيئة Python جاهزة، ومفتاح API محفوظ بأمان، وفكرة واضحة عن الكلفة والمخاطر قبل أن تكتب أول وكيل.

## شغّل الدرس

## 1. المتطلبات

| المتطلب | التفاصيل |
|---|---|
| Python | الإصدار 3.10 أو أحدث. الإصدار 1.x من مكتبة `anthropic` يتطلبه. |
| الطرفية (Terminal) | أي طرفية: Terminal في macOS، أو PowerShell في Windows، أو طرفية Linux. |
| حساب مطوّر | حساب في منصة Claude للمطوّرين (platform.claude.com) لإنشاء مفتاح API. لا تحتاجه لتشغيل الاختبارات. |

تحقّق من إصدار Python:

</div>
<div dir="ltr">

```bash
python3 --version
```

## 2. البيئة الافتراضية وتثبيت المكتبات

البيئة الافتراضية مجلد معزول يحمل مكتبات هذا المشروع وحده، فلا تتعارض مع مشاريعك الأخرى. نفّذ الأوامر الآتية من جذر المستودع:

</div>
<div dir="ltr">

```bash
# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate

# Windows (PowerShell)
py -m venv .venv
.venv\Scripts\Activate.ps1

# both
pip install -r requirements-dev.txt
```

</div>
<div dir="rtl">

يثبّت الملف `requirements-dev.txt` مكتبة `anthropic` (الإصدار 1.x) ومكتبة `pytest` للاختبارات.

## 3. مفتاح API: احفظه في البيئة، لا في الشيفرة

مفتاح API يشبه كلمة المرور: من يملكه يستطيع أن يستهلك رصيدك.

> [!WARNING]
> **القاعدة في هذه الدورة بلا استثناء:** المفتاح لا يُكتب في أي ملف شيفرة، ولا يُرفع إلى أي مستودع.

المكتبة الرسمية تقرأ المفتاح تلقائياً من متغير البيئة `ANTHROPIC_API_KEY`، فلا يحتاج كودك إلى ذكره أصلاً:

</div>
<div dir="ltr">

```bash
# macOS / Linux (current terminal session only)
export ANTHROPIC_API_KEY="paste-your-key-here"

# Windows PowerShell (current session only)
$env:ANTHROPIC_API_KEY = "paste-your-key-here"
```

</div>
<div dir="rtl">

ثم تأكّد أن كل شيء جاهز. السكربت الآتي يخبرك بوجود المفتاح دون أن يطبعه:

</div>
<div dir="ltr">

```bash
python lessons/00/check_setup.py
```

</div>
<div dir="rtl">

> [!TIP]
> **بديل:** إذا ثبّت أداة سطر الأوامر الرسمية `ant` وسجّلت الدخول بالأمر `ant auth login`، فإن المكتبة تقرأ ملف التعريف (Profile) المحفوظ تلقائياً دون متغير بيئة.

### قواعد حماية المفتاح

1. لا تكتبه في الشيفرة، ولا في ملفات الإعداد التي تُرفع إلى Git. الملف `.env` مدرج في `.gitignore`، والملف `.env.example` قالب فارغ فقط.
2. لا تلصقه في محادثة أو لقطة شاشة أو سؤال في منتدى.
3. أنشئ مفتاحاً منفصلاً لكل مشروع، حتى تستطيع إلغاء واحد دون أن تتعطل البقية.
4. إذا تسرّب المفتاح، فألغِه فوراً من لوحة التحكم وأنشئ غيره. الحذف من سجل Git لا يكفي، لأن النسخ القديمة قد تكون نُسخت في مكان آخر.
5. اضبط حداً للإنفاق من صفحة الحدود (Limits) في لوحة التحكم قبل أن تجرّب الحلقات.

## 4. الكلفة: كيف تُحسب؟

تُحسب الكلفة بعدد الرموز (Tokens). الرمز قطعة من النص قد تكون كلمة أو جزءاً منها. هناك سعران: سعر لرموز الإدخال (ما ترسله)، وسعر أعلى لرموز الإخراج (ما يولّده النموذج).

الأسعار المنشورة لواجهة Claude البرمجية في نوفمبر 2026، بالدولار لكل مليون رمز:

| النموذج | المعرّف (Model ID) | الإدخال | الإخراج |
|---|---|---|---|
| Claude Opus 5.5 | `claude-opus-5-5` | 4.00 | 20.00 |
| Claude Sonnet 5.5 | `claude-sonnet-5-5` | 2.00 | 10.00 |
| Claude Haiku 5.5 | `claude-haiku-5-5` | 0.10 | 0.50 |

> [!IMPORTANT]
> **مهم**
>
> الأسعار تتغيّر. راجع صفحة الأسعار الرسمية قبل أي تقدير جادّ. سعر Haiku 5.5 أعلاه للطلبات حتى 100 ألف رمز إدخال.

**ثلاث حقائق تؤثر في فاتورتك:**

1. **رموز التفكير تُحسب إخراجاً.** النماذج الحديثة تفكّر قبل أن تجيب، وتلك الرموز تُدفع بسعر الإخراج حتى لو لم تظهر لك نصاً. لذلك نضبط مستوى الجهد (Effort) في الدروس على `low` للتجارب.
2. **الحلقة تعيد إرسال المحادثة كلها في كل خطوة.** الوكيل الذي يأخذ 5 خطوات يرسل التاريخ المتراكم 5 مرات. هذا ما يجعل حدّ الخطوات وحدّ الكلفة ضرورة لا ترفاً (الدرس 03).
3. **عدد الرموز في النص العربي قد يختلف عن الإنجليزي** لنفس المعنى. لا تخمّن: نقطة النهاية `count_tokens` تعدّ الرموز قبل الإرسال.

**مثال حسابي توضيحي** (أرقام افتراضية، لا قياس فعلي): تشغيل في الدرس 02 من 3 طلبات، كل طلب نحو 1,500 رمز إدخال و300 رمز إخراج على Opus 5.5:

</div>
<div dir="ltr">

```text
input:  3 x 1,500 = 4,500 tokens  x $4  / 1,000,000 = $0.018
output: 3 x   300 =   900 tokens  x $20 / 1,000,000 = $0.018
total ≈ $0.036
```

</div>
<div dir="rtl">

### اختيار النموذج ومستوى الجهد

تستخدم الدروس افتراضياً `claude-opus-5-5`، ويمكنك التغيير دون تعديل الشيفرة:

</div>
<div dir="ltr">

```bash
export AGENT_MODEL="claude-sonnet-5-5"   # model id
export AGENT_EFFORT="low"                # low | medium | high | xhigh | max
```

</div>
<div dir="rtl">

## 5. ملاحظات السلامة قبل أن تبدأ

الوكيل ليس محادثة فقط؛ إنه برنامج **يُنفّذ أفعالاً**. لذلك:

- **شغّل الأدوات في صندوق رمل (Sandbox).** أدوات الملفات في الدورة لا تصل إلا إلى مجلد محدد.
- **امنح أقل صلاحية تكفي (Least Privilege).** لا تعطِ وكيلاً تجريبياً صلاحية الحذف أو الإرسال أو الدفع.
- **اجعل الأفعال الخطرة تحتاج موافقة إنسان.** ستبني ذلك بنفسك في الدرس 02.
- **لا تجرّب على بيانات حقيقية أو أنظمة إنتاج.** استعمل الملفات التجريبية المرفقة.
- **مخرجات الأدوات بيانات وليست أوامر.** النص الذي يقرؤه الوكيل من ملف قد يحتوي تعليمات مدسوسة (Prompt Injection)، وسنتعامل مع ذلك في الدرس 03.

## 6. تشغيل الاختبارات (دون مفتاح ودون إنترنت)

كل مثال في الدورة له اختبار يستعمل عميلاً وهمياً (Mock Client) يعيد ردوداً مكتوبة مسبقاً، فلا تُرسَل أي طلبات حقيقية:

</div>
<div dir="ltr">

```bash
python -m pytest
```

</div>
<div dir="rtl">

إذا نجحت الاختبارات، فبيئتك جاهزة. وإذا أردت أن تفهم كيف يُختبر وكيل دون نموذج حقيقي، فاقرأ `tests/fakes.py`.

## أخطاء شائعة

| الخطأ | ما يحدث | الصواب |
|---|---|---|
| كتابة المفتاح داخل `client = anthropic.Anthropic(api_key="...")` | يتسرّب مع أول رفع للمستودع | استدعِ `anthropic.Anthropic()` بلا وسائط، ودع المكتبة تقرأ البيئة |
| تثبيت المكتبات خارج البيئة الافتراضية | تعارض الإصدارات بين المشاريع | فعّل `.venv` قبل `pip install` |
| استعمال Python 3.9 أو أقدم | فشل تثبيت `anthropic` 1.x | حدّث إلى 3.10 أو أحدث |
| تصدير المتغير في طرفية وتشغيل الكود في أخرى | `ANTHROPIC_API_KEY is not set` | متغير `export` يعيش في الجلسة الحالية فقط |

## اختبر نفسك

1. أين يجب أن يُحفظ مفتاح API؟
2. لماذا يمكن أن تكون كلفة الوكيل أعلى بكثير من كلفة سؤال واحد؟
3. هل تُحسب رموز التفكير في الفاتورة؟
4. ماذا تفعل إذا رفعت المفتاح خطأً إلى مستودع عام؟

<details>
<summary><b>الإجابات</b></summary>

1. في متغير البيئة `ANTHROPIC_API_KEY` (أو ملف تعريف `ant`)، وليس في أي ملف شيفرة.
2. لأن الحلقة تعيد إرسال المحادثة المتراكمة في كل خطوة، وكل خطوة تولّد رموز إخراج وتفكير.
3. نعم، تُحسب بسعر الإخراج حتى لو لم تظهر نصاً.
4. تلغيه فوراً من لوحة التحكم وتنشئ مفتاحاً جديداً. حذفه من سجل Git وحده لا يكفي.

</details>
